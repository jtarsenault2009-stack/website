# I Love Izabella ❤️
Interactive mobile website with four photo placeholders. The visitor must discover the correct order without being told.

Edit all messages near the top of `script.js`. Later, replace the `null` photo values with paths such as `images/favorite.jpg`.

For GitHub Pages: upload `index.html`, `style.css`, and `script.js` to your repo, then Settings → Pages → Deploy from branch → main → root.
